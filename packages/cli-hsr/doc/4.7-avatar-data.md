# 4.7 角色新增数据与“点名技”

## 输出位置

| 数据 | 输出字段 | 结构 |
|---|---|---|
| 奇缘星魂 | 角色详情 `exRanks[]` | 独立于 `versions[].ranks`，归属角色本体 |
| 阿哈系列技能 | 角色详情 `versions[].seriesSkills[]` | 与当前版本的 `skills` 同级，每个技能聚合自己的 `levels` |
| 昔涟忆灵技能目标 | 忆灵 `skills[].avatarId` | 在既有技能上补目标角色 ID，保留 `picture` |
| 姬子助战技可用角色 | 角色详情 `versions[].skills[].linkToAvatarIds`、`linkToAvatarIdsSimplified` | 在两个既有助战技能上分别保留完整、简化列表 |

角色使用 `avatars/index.json` 主列表与 `avatars/<id>.json` 明细布局。主列表省略 `promotions`、`versions`、`exRanks`，通过布尔字段 `hasExRank` 标识角色是否拥有奇缘星魂。忆灵沿用 `servants/index.json`。以上是发布数据契约，不是文档依赖文件。

“点名技”是玩法概念。三种技能关联沿各自既有实体输出，不建立统一数据域。单目标角色字段统一为 `avatarId`，姬子的复数列表保留各自语义。

## 奇缘星魂

### 身份、归属和资源

`AvatarExRankConfig` 当前有 3 行。主键为 `PHFMCACHFIJ`，显式角色外键 `ACCJKGEKHKP` 关联 `AvatarConfig.AvatarID`，不能用 ID 前缀推导归属。

| 角色 | AvatarID | 奇缘星魂 ID | 关联技能 | 解锁物品（数量均为 1） | 视频 ID |
|---|---:|---:|---:|---:|---:|
| 景元 | 1204 | 120401 | 120404 | 131204 | 15010 |
| 丹恒•饮月 | 1213 | 121301 | 121304 | 131213 | 15011 |
| 黄泉 | 1308 | 130801 | 130804 | 131308 | 15009 |

这三个 ID 与各角色普通第一星魂的 `AvatarRankConfig.RankID` 重号，但表示不同对象，必须区分表和数据域；不能并入普通六星魂或追加成第七阶。当前主表没有版本选择字段，因此 `exRanks` 挂在角色本体。三名角色当前均无增强版本记录。

| 原始字段 | 输出及关联 |
|---|---|
| `PHFMCACHFIJ`、`ACCJKGEKHKP` | `id`、`avatarId` |
| `OENAMINOLLF`、`NMAHGFAPENI` | 明文文本键本地化为 `name`、`desc` |
| `AGOHEFBOPNO.Hash` | 64 位 TextID，本地化为 `effectText` |
| `OIBKPJEGPOK.Hash` | 32 位字符串哈希，原样保留为 `triggerHash` |
| `OLOIFNNLKJP`、`AIAFHMFPFMN` | 经资源 URL 转换为 `icon`、独立背景 `picture` |
| `DPPHHNMHPAK`、`NNFEGHLLEPH` | `panelPrefabPath`、`rankAbilities`，保留原资源路径和能力标识 |
| `NNACKOBKFGE` | `{ Value }` 扁平化为 `params`，顺序和数值保持 |
| `BDECHFIJBFA` | `extraEffectIds` → `ExtraEffectConfig.ExtraEffectID` |
| `PKBNJLOLPBM` | `unlockCost: { itemId, num }` → 通用 `ItemConfig.ID` |
| `ODEKADIBFAO` | `guideVideoId` → `GuideVideoConfig.VideoID` |
| `NJNDLOFDBHB` | Int32，业务含义未确定 |

`NJNDLOFDBHB` 在景元行缺省，另两行为 `10`；保留原字段和值，不解释为削韧，不补默认值。文本哈希通过 JSONBig 读取，不能与 32 位 `triggerHash` 混用。

背景直接使用表内 `UI/UI3D/Rank/_dependencies/Textures/<AvatarID>/<AvatarID>_ExRank_1.png` 并按既有 `srtools` 规则转换，不由普通星魂序号拼接。`UI/Avatar/Rank/DLC/AvatarSpRank3DPanel_<AvatarID>.prefab` 是单独保留的面板路径，不能当图片 URL。解锁物品属于 `AvatarExRankMaterial`，视频为 `Activity_ExRank_<AvatarID>.usm`；提取器只输出关联，不生成获取流程或玩家状态。

### 技能与玩法变体

`AvatarSkillConfig.RelatedExRankIDList` 为正向引用：三个天赋技能各有 15 个等级，共 45 条引用。普通技能保留 `relatedExRankIds`；奇缘星魂的 `relatedSkillIds` 按技能 ID 汇总、跨等级去重。此关联不等同于普通星魂的 `RatedRankID`，也不证明具体脚本替换行为。

货币战争的 `GridFightBackRoleExRank` 是独立玩法配置。当前 S2 景元 `RoleID=120402` 引用 `ExRankID=120401`，参数为 `[1,2,6,12,4,20]`，普通景元为 `[1,2.4,6,12,4,20]`。四个对应前台技能保留 `relatedExRankIds`；后台变体没有并入普通角色 `exRanks`，消费端不能直接复用普通角色参数。

实现：[AvatarExRankExtractor](../extract/avatar/AvatarExRankExtractor.ts)、[原表 schema](../schema/AvatarExRankConfig.ts)、[HsrAvatarExRank](../../gacha-game-types/src/games/hsr/HsrAvatarExRank.ts)。

## 星神★阿哈：版本内的系列技能

`AvatarSeriesSkill` 当前有 18 行、9 个技能。按 `(SkillID, Level)` 连接 `AvatarSkillConfig`，`AvatarID` 表示技能所属角色，`RelateAvatarIDList` 给出关联角色。

阿哈 `151129` 的两条配置具有相同显式列表：`[1506,1505,1501,1502,1503,1513,8009,8010,1511]`。该集合恰好覆盖当前 9 个欢愉角色，但提取器依赖源列表，不按命途筛选，也不硬编码目标。

| 角色 ID | 系列技能 ID |
|---|---|
| 1506、1505、1501、1502、1503 | 150629、150529、150129、150229、150329 |
| 1513、8009、8010、1511 | 151329、800929、801029、151129 |

`AvatarExtractor.getSkillInfo` 根据当前版本的 `SkillList` 独立构造 `seriesSkills`：从该版本的系列记录展开非空角色列表，匹配相同 `Level` 和完整 `UnlockCondition`，再读取对应技能等级。当前只有阿哈具有非空关联列表，因此只有阿哈的版本输出额外集合。

最终为 **9 个技能、每个 2 个等级**，保留显式关联顺序。`HsrAvatarSeriesSkill` 继承普通技能结构，`id/name/icon/desc/type/effect/levels` 位于技能对象顶层；额外保存必填 `avatarId`、`framePrefab`、`specialTagPrefab`、`relatedAvatarIds`。每个等级保留自己的参数和解锁元数据：

| 等级 | `unlockCondition` | `specialTag` |
|---|---|---|
| 1 | `{ type: "AvatarLevel", param: "1511.0" }` | 缺省 |
| 2 | `{ type: "AvatarEidolon", param: "1511.2" }` | 「欢愉」跃升 |

条件参数是字符串，不能当小数或普通技能材料升级条件解析。两级技能参数独立，例如阿哈分别为 `[0.1,0.3,0.12]` 和 `[0.1,0.6,0.2]`。原表未给出“被强化的原技能 ID”外键，不从描述中的技能名称猜测关联；战斗状态条件仍由原始描述表达。

各角色普通 `skills` 保留原始 `SkillList` 的全部内容。阿哈自身 `151129` 同时存在于普通技能和系列集合；消费端单独展示系列分组时可按 ID 避免重复展示。阿哈特殊行迹的 `151131 / SkillAeon` 不属于本系列关系，继续由既有技能、行迹数据提供。

## 昔涟：忆灵技能目标

`AvatarServantSkillLink.SkillID` 连接 `AvatarServantSkillConfig.SkillID`，`LinkToAvatarID` 连接角色。德谬歌 `11415` 的 `SkillIDList` 包含当前全部 14 个链接技能。

`ServantExtractor` 在已有技能上补 `avatarId`，继续从 `TarotFigurePath` 生成 `picture`，保持原技能顺序及各技能 10 个等级，不另按链接表 `Order` 排序或复制一套技能。角色通过既有 `servantId=11415` 关联德谬歌。

当前链接中的开拓者只有 `8007`，没有 `8008`，不自行展开性别等价关系。`AvatarServantConfig` 无主人角色外键，不能用技能 ID 前缀推导归属。

## 姬子•启行：助战技可用角色

`AvatarSkillLink` 按 `SkillID` 关联已有技能。姬子 `151022`、`151025`、`151026` 均为 `Assist`，各有 15 级；行迹 `1510004` 的 `LevelUpSkillID` 同时包含天赋 `151004` 和这三个助战技。

| 技能 ID | 完整 `linkToAvatarIds` | 简化 `linkToAvatarIdsSimplified` |
|---:|---|---|
| 151022 | 无链接记录，字段缺省 | 无链接记录，字段缺省 |
| 151025 | `[8001,1002,1213,1414,1313]` | `[8001,1002,1313]` |
| 151026 | `[1001,1413,1004,1003]` | `[1001,1004,1003]` |

这些列表表达可使用相应特殊分支的角色，不能当作 buff 受益名单。全队助战次数来自天赋描述，各分支效果范围由其技能文本表达。完整、简化列表均保留；没有链接记录与表内空列表保持区别，通用助战 `151022` 仍在普通技能列表中。

技能关联实现与类型：[AvatarExtractor](../extract/avatar/AvatarExtractor.ts)、[ServantExtractor](../extract/avatar/ServantExtractor.ts)、[HsrGameAvatar](../../gacha-game-types/src/games/hsr/HsrGameAvatar.ts)。
